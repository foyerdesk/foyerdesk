# FoyerDesk brand assets

| File | Use |
|---|---|
| `logo.svg` | Horizontal logo on light backgrounds |
| `logo-dark.svg` | Horizontal logo on dark backgrounds (README uses both through `<picture>`) |
| `icon.svg` | Standalone mark (the white bubble has a thin blue outline so it stays visible on white) |
| `favicon.svg` | Favicon, same artwork |
| `social-preview.png` | GitHub social preview, 1280 × 640, under 1 MB |

The wordmark is live text (Inter, then Arial, Helvetica, any sans-serif). Where exact lettering matters (print, app stores) export the logo to paths first.

GitHub cannot set the social preview from the API. Upload `social-preview.png` in the repository: Settings, General, Social preview.

Source kit with the original 1774 × 887 preview: `foyerdesk-references/foyerdesk-brand-kit` (outside this repository).
